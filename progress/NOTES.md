# Working notes

## Decisions

- Schema mirrors starwars-db (entities / relationships / metadata /
  timeline_events / timeline_entities / entity_images) so the same wiki works,
  plus domain tables for list-valued game data (learnsets, parties, encounters,
  map events, scripts, texts, dialogue, flags, art).
- `entities.csv` holds the union of scalar attributes for all entity types
  (sparse columns, like starwars-db's SWAPI union). List attributes are JSON.
- Everything game-derived is regenerated by `tools/build.py`; lore goes in
  `curated/`. This keeps a re-extraction (e.g. after pokeemerald changes)
  from clobbering hand-written work.
- NPC entities exist for every object event (including item balls, boulders,
  cuttable trees). Their `graphics` column tells you which are props.
- Dialogue attribution walks the call/goto graph from the object/sign/trigger
  script (depth ≤ 8; shared `Common_*`/`EventScript_*` scripts only 2 levels
  deep) — so a few generic lines (Pokémon Center nurse etc.) repeat per NPC.
  `dialogue.shared_script` marks them.
- `texts.speaker_label` is parsed from the `NAME: ` prefix the game uses for
  named speakers; anonymous NPC lines have no label.

## Gotchas

- `.string` text uses `\n` (line), `\l` (scroll), `\p` (new box) and `$`
  (end). `texts.text` is cleaned (boxes → blank line), `texts.text_raw` is exact.
- 25 `SPECIES_OLD_UNOWN_*` placeholders exist (collection `unused-placeholder`).
- Items `ITEM_034` etc. are unused slots (collection `unused`).
- TM items are keyed `ITEM_TM_<MOVE>`; the TM number is `tm_hm_number`.
- `OBJ_EVENT_GFX_VAR_0..F` are runtime-chosen sprites (rival, opponents).
- ~29% of texts are not referenced by any overworld script: they are used
  from C (`src/`) or via `loadword`/tables. A8 will add C-side strings.

- `area_progression.badges_expected` is curated (prefix rules per map); the auto value from the timeline is overwritten. Rematch trainers (`*-2`..`*-5`) are excluded from trainer level ranges.
- `npc --portrays--> character` links only use character-specific sprites (e.g. `object-gfx:maxie`), not generic ones like `man-1`.
- Story `year` = chapter (1..45), entity `story_act` = act (1..7 main story, 8 post-game). Timeline `era` names the act.
